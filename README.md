# 🎵 Mixtapes4U

A romantic mixtape maker that integrates with Spotify and Apple Music APIs.

## Features
- ✅ Search and browse songs
- ✅ Create personalized mixtapes
- ✅ Add romantic notes for each song
- 🚧 Spotify API integration (coming soon)
- 🚧 Apple Music integration (coming soon)
- 🚧 Lyrics display (coming soon)

## Tech Stack
- React
- Spotify Web API
- Apple MusicKit JS
- Firebase (for data persistence)

## Development
